Frontend Developer Offline

to $2000

Привіт!
Потребуємо Frontend Developer (Next.js + GraphQL) для допомоги у створенні інтернет-магазину. 
Це буде part-time зайнятість (прогнозовано 10-15 годин на тиждень). 
За тривалістю 2-3 місяці.


Опис проєкту:
Ми шукаємо досвідченого Frontend-розробника для завершення проєкту інтернет-магазину на Next.js. 
Проєкт вже частково реалізований, необхідно доопрацювання та інтеграція з бекендом через GraphQL. Бекенд розроблений на базі Vendure з кастомною бізнес-логікою, його підтримує окремий розробник.


Шукаємо спеціаліста з:
- Досвідом роботи з Next.js;
- Вмінням працювати з GraphQL, досвід інтеграції API;
- Навичками роботи із системою контролю версій (Git);
- Базовим розумінням роботи сервера та деплою на VPS.

Знанням основ e-commerce буде плюсом!


Потребуємо допомогу у:
- Завершенні розробки фронтенд-частини інтернет-магазину;
- Інтеграції фронтенду з бекендом через GraphQL;
- Тестуванні та налагодження функціональності;
- Деплої фронтенд-частини проєкту.

Також буже необхідно взаємодіяти з бекенд-розробником для уточнення API та логіки.

Як будемо працювати:
- Повністю віддалено;
- У гнучкому графіку (приблизно Х годин на день);
- По тривалості 2-3 місяці;
- По оплаті орієнтуємось на очікування кандидатів 👌

Required skills

React.js, Next.js, GraphQL

Required languages

English B1 - Intermediate
