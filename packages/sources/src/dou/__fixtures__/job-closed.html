Senior Full-stack Developer (React/Node.js) (вакансія неактивна)

віддалено $4000–6000

Job description

We’re looking for a senior software engineer to join our core team and work on a technically challenging cybersecurity project.

Our client is a well-funded startup ($7.5M raised in seed) building the first application detection & response platform. Using OpenTelemetry and trace analytics, their solution enables enterprises to stop attacks with in-application context into all runtime transactions and behaviors. The company’s mission is to revolutionize application security with real-time anomaly detection and monitoring, automated incident response and rich context.

You’d be tasked with building new functionality for the web portal, which is the primary interface customers interact with when using the product.

Client side tech stack: React 18, Typescript, Jotai, React-query for state management. BFF: ExpressJS, Typescript, TypeORM, Postgres. Microfront-end architecture built in-house.

Responsibilities

— Work closely with the tech lead, product owner and other engineers to identify, plan and develop new features

— Write clean, testable and readable code using appropriate software design patterns

— Continuously assess and improve the existing codebase cleanliness and performance

— Review, maintain and refactor existing code to meet the requirements for improved or new features

— Share your engineering wisdom with the rest of the team

Required skills & experience

— 4+ years of commercial experience as a front-end oriented full-stack developer with the JS ecosystem. There’s more work on the front-end (around 70-80%)

— You have an eye for design, attentive to UI/UX details, and aspire to perfection

— Good knowledge and experience with PostgreSQL and TypeORM

— Passion for writing clean, well-commented, readable and reusable code

— General understanding of core algorithms, data structures, their applications and tradeoffs

— Good grasp of version control tools

— Upper-intermediate+ level of English

Bonus points

— Experience in the cybersecurity domain

— Experience with micro-frontend architecture

— You’re a contributor to open-source software or run your own pet projects

— Familiarity with AWS and core AWS services

— Leadership experience

What’s in it for you

— Opportunity to become a part of a boutique software consultancy, working with well-known international customers and highly complex challenges

— Competitive salary

— Paid vacation and sick leave

— Remote-friendly culture

— Internal tech talks and mentorship

— Yearly learning & development budget

— PE administration support

— Yearly company ski trips (after Ukraine’s victory 🇺🇦⛷️)
